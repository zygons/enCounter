# AI Assistance Disclosure

enCounter has been developed with assistance from generative AI tools. AI assistance has been used for tasks including code drafting, debugging, documentation, project organization, testing suggestions, release preparation, and review suggestions.

## Human responsibility

AI-assisted output is treated as a development aid, not as an autonomous maintainer. The project maintainer decides what is included in enCounter, reviews and tests changes before release, and addresses defects or licensing issues that are identified.

## Licensing and contributions

AI assistance does not change enCounter's license. enCounter is distributed under the **MIT License**.

Contributors may use AI-assisted development tools, but contributors remain responsible for the material they submit and must have the right to contribute it under the MIT License. Contributors should review AI-assisted work for correctness, security, originality, and license compatibility before submitting it.

## Runtime behavior

The current enCounter Alpha does not include generative-AI functionality and does not intentionally send encounter, Library, or campaign data to an AI service. AI used during development is separate from how the application operates for users.

## Transparency

This disclosure is provided so users and contributors can make an informed decision about using or contributing to the project.
