# Contributing to enCounter

Thank you for considering a contribution.

## License for contributions

Unless explicitly agreed otherwise in writing, code, documentation, and other copyrightable material intentionally submitted for inclusion in enCounter is submitted under the project's **MIT License**.

By contributing, you represent that you have the right to submit the contribution under those terms.

## Development expectations

- Do not commit user backups, exports, imports, saved campaign data, or personal files.
- Do not commit generated `build`, `dist`, or `release` folders.
- Keep version identifiers centralized where practical.
- Preserve existing license and copyright notices.
- Test both the DM Console and Player Display when changing shared data or synchronization behavior.
- If a change is platform-specific, state whether it was tested on Windows, Linux, or both.

## AI-assisted contributions

AI-assisted development is permitted. If you use a generative AI tool to help prepare code, documentation, tests, or other material, you remain responsible for what you submit.

Review AI-assisted work for correctness, security, originality, and license compatibility before submitting it. Do not submit material you do not have the right to contribute under the MIT License.

## Pull requests

A useful pull request should explain what changed, why it changed, and how it was tested. Keep unrelated changes separate when practical.
